# NutriPulse Elite

NutriPulse Elite is a high-performance wellness dashboard prototype. It features biometric tracking, nutritional analysis, and mindfulness protocols in a sleek, obsidian-themed interface.

## 🚀 Key Features

- **Biometric Dashboard**: Real-time visualization of your health data.
- **Intake Log**: Track your nutritional intake with precision.
- **Mindfulness Protocols**: High-quality audio tracks for meditation and focus.
- **Habit Matrix**: Systematize your daily routines for peak performance.
- **Command Center**: Manage reminders and specialized notes.
- **Local Vault**: Data is stored securely in your browser's local storage.

## 🛠️ Tech Stack

- **React 19 & TypeScript**: Type-safe frontend architecture.
- **Vite 6**: Lightning-fast build and development.
- **Tailwind CSS 4**: Modern, utility-first styling.
- **Lucide React**: High-precision iconography.
- **jsPDF**: Generate performance reports locally.

## 🏁 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```

## 🔒 Privacy & Data

NutriPulse Elite operates entirely on your local machine. No data is transmitted to external servers. All information is stored in your browser's `localStorage`.
